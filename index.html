Proxcrome
Remote Chrome via noVNC
Deploy

Full browser in a container

Run a password-protected Chrome session in the browser.

Proxcrome exposes a real Google Chrome desktop through noVNC. GitHub Pages is only the guide page. The actual browser session runs in Docker on a host that supports HTTPS and web access.

Connect to noVNC View repo

1. Run the browser

Deploy the Docker container on a VPS, Codespace, or local cloud VM.

docker-compose up --build

2. Connect securely

Open the noVNC endpoint over HTTPS and enter the VNC password.

https://browser.example.com/vnc.html

3. Use Chrome

Browse normally in a full browser session, including cloud gaming, web apps, and services.

Connection guide

  1. Set a strong VNC_PASSWORD.
  2. Deploy the Docker host with HTTPS.
  3. Expose the noVNC web UI publicly through a reverse proxy.
  4. Use the public URL to connect to the full Chrome remote desktop.
This page is a guide only. GitHub Pages cannot host the Chrome browser session itself.

Production example

docker run -d --rm \
  -p 8080:8080 \
  -p 5900:5900 \
  -e VNC_PASSWORD=your-strong-password \
  -e TARGET_URL=https://www.xbox.com/play \
  --name proxcrome \
  camdenbecker11-sudo/proxcrome:latest

Then expose https://browser.example.com to your reverse proxy and point it to the container's port 8080.
